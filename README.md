# 🏆 올리 (All-Re) - 100개 웹사이트 통합 관리 포털

> **"1인 기업가의 100개 웹서비스 빌드 챌린지를 위한 통합 제어 센터 및 성과 측정 대시보드"**
>
> **올리 (All-Re)**는 기획부터 개발, 운영까지 홀로 감당하는 1인 크리에이터 및 개발자를 위한 프로젝트 관리 대시보드입니다. 여러 도메인에 흩어져 있는 웹 서비스들을 하나의 포털에서 통합 관리하고, 실시간 트래픽 및 수익 지표를 시각화하여 목표 달성(100개 웹사이트 빌드)을 돕습니다.

<br>

## 🚀 주요 기능 (Key Features)

### 1. 📊 챌린지 프로그레스 트래커 (Challenge Tracker)
* **목표 달성도 시각화**: 100개 웹사이트 빌딩 목표의 실시간 진척도(%)를 부드러운 애니메이션 바와 숫자로 직관적으로 제공합니다.
* **통계 카드 세부 분석**: 카테고리별(AI/3D, 게임, 비즈니스, 유틸리티 등) 및 상태별(운영 중, 개발 중) 프로젝트 개수를 자동으로 집계하여 상태판을 갱신합니다.

### 2. 💰 비즈니스 지표 실시간 집계 (Financial & Traffic KPI)
* **총 월 예상 수익**: 등록된 모든 활성 서비스의 수익 지표를 합산하여 실시간 총매출 통계를 제공합니다.
* **총 월 활성 방문자**: 전체 웹서비스들의 월간 누적 활성 방문자수(MAU) 지표를 시각적으로 실시간 모니터링합니다.

### 3. 🔍 다이내믹 필터링 & 검색 시스템 (Dynamic Filters)
* **실시간 텍스트 검색**: 이름, 설명, 태그를 입력하는 즉시 해당하는 웹 서비스를 고속 필터링합니다.
* **카테고리/태그 클라우드**: 동적으로 생성되는 태그 클라우드 및 탭 형태의 카테고리 셀렉터를 통해 원하는 속성의 웹사이트들을 한눈에 걸러냅니다.

### 4. 💡 아이디어 샌드박스 보드 (Idea Sandbox)
* **아이디어 신속 기록**: 생각나는 비즈니스 모델이나 웹앱 기획안을 즉각 메모하고 보관할 수 있습니다.
* **프로젝트 즉시 변환**: 샌드박스에 보관된 아이디어를 원클릭으로 신규 웹사이트 등록 양식으로 즉시 로드하여 개발 프로젝트로 신속히 전환합니다.

### 5. ⚡ 서버 헬스 체크 & 업타임 모니터 (Health Monitor)
* **실시간 핑(Ping) 테스트**: 100개 관리 사이트 전체의 서버 응답 상태 및 핑 타임(ms)을 원클릭으로 모니터링합니다.
* **상태 시각화**: 정상(초록), 지연(주황), 연결불가(빨강) 인디케이터로 사이트 장애 여부를 즉각 판단할 수 있습니다.

### 6. 🔔 통합 알림 & 고객 문의 수신함 (Central Inbox)
* **통합 메시지 관리**: 여러 사이트로 접수되는 고객 문의 폼 메시지 및 시스템 경고를 한곳에 수집하여 읽음/미읽음 관리 및 필터링을 제공합니다.
* **실시간 알림 뱃지**: 헤더에서 읽지 않은 문의 카운트를 실시간으로 확인 가능합니다.

### 7. 🔒 SSL / 도메인 만료 D-Day 트래커 (Expiration Tracker)
* **만료 임박 경고**: 도메인 및 SSL 인증서 만료 예정일을 등록하면 카드에 D-Day 태그가 노출됩니다.
* **임박 네온 하이라이트**: D-30일 이하 임박 시 주황/빨강 경고 글로우 애니메이션 뱃지로 전환되어 갱신 시점을 놓치지 않도록 방지합니다.

### 8. 📥 데이터 유연성 - 백업 및 복원 (Export & Import)
* **데이터 백업 (JSON Export)**: 등록된 전체 포트폴리오 데이터와 수신 알림 상태를 `.json` 포맷으로 즉시 백업합니다.
* **데이터 복원 (JSON Import)**: 백업된 JSON 파일을 불러와서 포털 데이터 상태를 신속히 복원합니다.

<br>

## 🛠️ 기술 스택 (Tech Stack)

* **Core**: `HTML5`, `Javascript (Vanilla ES6+)`
* **Styling**: `Vanilla CSS`
  * 다크 모드(Dark Theme) 최적화
  * 글래스모피즘(Glassmorphic Layout) 및 네온 글로우 스타일 반영
  * 모바일-태블릿-데스크탑 전 영역 반응형 그리드 시스템(Responsive Grid) 적용
* **Data Layer**: 브라우저 내장 `LocalStorage`를 활용한 제로-서버 로컬 데이터 영구 보존(Data Persistence)

<br>

1. 이 저장소를 로컬 컴퓨터로 클론합니다:
   ```bash
   git clone https://github.com/leegoheun9-bit/All-Re.git
   ```
2. 프로젝트 폴더 내 `index.html` 파일을 크롬 등 웹 브라우저에서 더블 클릭하여 실행합니다.
   * *또는 VS Code Live Server 확장을 사용하여 로컬 개발 서버 환경에서 가동하셔도 좋습니다.*
